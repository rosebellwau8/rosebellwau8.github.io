结论先行（摘要）

一句话总判断：截至 2026-08，AI 的「最强」已分不出唯一赢家——各维度最强分属不同模型，且不同评测口径不能直接横向比较。判断模型「够不够强」，关键看三件事：你派的活是几分钟级短任务（可尝试）还是数小时级长任务（别指望）；广告窗口和实际可用是两回事；以及你能否稳定访问到最强模型（中国大陆通常有地区、网络等接入限制）。
  • 推理 / 写作 / 编程：日常推理与写代码已达到很高水平，部分旧基准接近饱和；但头部差异是否「对使用有意义」取决于具体任务，不宜一概而论。
  • Agent 自主性：短任务（分钟级）在部分基准上已超过报告的人类基线；长任务（数小时）可靠完成率仍然很低——这是当前公认的主要瓶颈。
  • 长上下文：广告 1M≠实际可用，真实可靠约在 200K 内，只有少数模型在 1M 处表现领先。
  • 价格：单次调用成本已较低（旗舰输出 $25–50 / 百万 token），但长上下文、长推理与多 Agent 工作流的总成本仍可能显著。
  • 大陆访问：三家最强官方 API 对中国大陆用户通常有地区、网络、账号与支付等限制，具体情况随渠道与政策变化。

维度一：通用推理与写作

最强水平结论

截至 2026 年 8 月 2 日，以 Artificial Analysis 综合指数看，Claude Opus 5 以 61 分领先，Claude Fable 5 与 GPT-5.6 Sol 紧随其后（分别为 60、59 分）。榜首随模型与评测版本更新频繁变化，不宜据此认定唯一的「全能最强」；「写作第一」也只能限定在综合盲测偏好榜内，不能直接推出中文写作或专业写作第一。
  1. 推理 + 写作综合（第三方智能指数）：Claude Opus 5（61 分）列 Artificial Analysis 智能指数第 1，Claude Fable 5（60 分）第二，GPT-5.6 Sol（59 分）第三。Fable 5 在 2026-06-09 发布时曾排名第 1，但截至 8 月已被 Opus 5 反超。
  2. 最难新推理基准 ARC-AGI-2：GPT-5.6 Sol 最大推理档 92.5%（2026-07-09 发布），是官方验证榜 SOTA；但 ARC-AGI-3（交互式自适应）全行业都很弱，最强 Claude Opus 5 也仅 30.2%——抽象流体推理仍是最短板的维度。
  3. 博士级科学推理（GPQA Diamond）已接近饱和：Gemini 3.1 Pro 与 GPT-5.6 Sol 并列约 94%，人类博士专家基线约 70%，前 10 名挤在 90–94%——在样本量很小（约 200 题）的基准上，2 分的差距落在置信区间内，不能简单称为「噪声」或据此排座次。
  4. 最难通识知识（Humanity's Last Exam）：第三方实测最高 Claude Fable 5 无工具 53.3%；Claude Opus 5 官方自报 56.3%（未验证）。
  5. 写作 / 对话（LMArena 盲测）：Claude Fable 5 约 1509 Elo 居首，但 LMArena 测的是用户对回答的综合偏好（受长度、语气、格式、话题分布与用户构成影响），不等于独立的写作能力测试；前 5 名差仅约 15–28 点，统计上接近平手。
  6. 一句话总结：日常推理、写作、问答类任务，最强模型质量已明显高于平均水平；但「最高分」之间的差异在多数窄基准上已很小，且不同榜单口径不一，选哪个差别不大这一判断需结合具体任务。

维度二：编程能力

最强水平结论

编程「最强」要分口径看：不同评测的数据集、scaffold（代理框架）与推理预算不同，分数不能直接拼成一条能力曲线；当前榜 97% 也只是某一口径下的结果，不是「截至 8 月的绝对最强」。
  1. 真实工程 issue 修复（SWE-bench Verified 当前榜）：当前榜上 Opus 5 约 97%、GPT-5.6 Sol 约 96.2%，但该榜高度饱和、区分度下降，且「厂商自选 scaffold」反映模型与优化代理栈的组合上限，不能直接等同于模型原生能力。
  2. 更难、抗污染的 SWE-bench Pro：口径复杂，不同数据集 / scaffold / 模型配置下分数差异很大，Scale 标准化公开集最高已达 GPT-5.4 xHigh 的 59.1%；不同口径的分数不可直接相减比较（需同一模型版本、数据集、任务数、工具 / 重试 / 并行设置、推理预算均相同）。
  3. 多语言代码编辑（Aider Polyglot）：GPT-5 high reasoning 88.0% 居首（改现有代码、跨文件改代码）[C 第三方]。
  4. 终端 / agent 式编程：厂商宣传 88–92%（GPT-5.6 Sol Terminal-Bench 2.1 88.8%），独立复测约 83%（GPT-5.5 + Codex CLI 83.4%）。这些分数说明已达到「可交付构建脚本 / CI/CD / 重构」的工程水平，但基准环境、工具与预算固定，现实项目还包含需求澄清、环境差异、隐性约束与安全责任，仍有可观比例的专业任务失败。
  5. 竞赛编程：Google 宣传 Gemini 3 Deep Think 3455 Elo（超过除 7 人外所有人类），独立实时追踪最高 DeepSeek V4 Pro 3206。
  6. 一句话总结：写代码、改代码、自动化脚本已非常强且便宜；但涉及「多步 + 长时 + 无人复核」的工程任务，可靠度仍取决于具体口径，不能笼统说「已可交付」。

维度三：Agent 自主性

最强水平结论

AI Agent 自主性的分水岭在「时长」与「评测口径」：在 OSWorld-Verified 这套桌面操作基准上，领先系统的成功率已超过该基准报告的人类基线；但「单一基准超人类基线」不能直接推广为「所有分钟级短任务都已超过人类」。长时任务（数小时）仍是公认的主要短板。
  1. 桌面 / 浏览器操作（短任务）：OSWorld-Verified 最强模型 85%，该基准报告的人类基线约 72.4%。需注意：排名对象通常是「模型 + 代理框架 + 工具配置」而非纯模型；人类基线采样方式可能与 AI 测试条件不同；且该基准团队曾强调其远未饱和，超过某个人类基线不等于到达任务上限。WebArena 最强约 71–74%，低于人类基线约 78%，说明不同 web 基准结论不一。
  2. 单次能，重复不可靠：在 τ-bench 的重复运行测试中，Opus 4.8 的 pass@1 为 78%，而实测 pass^8 为 56%。pass^8 是实测指标（反映重复运行稳定性），不应简单理解为在「每次独立」假设下计算的 0.78^8（约 13.7%）；二者不矛盾。
  3. 长时任务（数小时）是最大短板，但两个数字来自不同评测，需分开看：

- METR 主要测软件、ML、网络安全等可清晰验收的任务，其「时间视野」指人类专家完成该任务所需时间；按 50% 成功率算约 14.5 小时——这是「人类用时」，不等于「Agent 连续稳定运行 14.5 小时」。 - OSWorld 2.0 测真实电脑环境中的长流程操作，受界面状态、错误累积与环境恢复影响；真人中位 1.6 小时的任务，完整完成率约 20%。 - 两个数字针对不同任务类型与评测设定，可同时成立，但不能混为一谈。

  1. 一句话总结：能较放心交给 agent 的是「单次几分钟内、失败可重试、有人抽查」的活；连续数小时无人监督的活，2026 年 8 月仍不能放心交给它。

维度四：多模态

最强水平结论

多模态最强的不是「一个全能模型」，而是分场景各占山头；视频生成赛道各家各有所长，「最强」需先明确评判标准。
  1. 图像理解 / 视觉问答：头部已饱和（MMMU-Pro 系约 83–85%），最强在 GPT-5.6 Sol、Gemini 3.5 Flash、Claude Opus 5 之间，差距约 2 个百分点——单看基准已分不出明显赢家。
  2. 视频生成：Sora 已停服，赛道各家各有所长。OpenAI 已确认 Sora 消费者产品于 2026-04-26 停止服务。关于其成本与留存率，媒体出现过多种未经 OpenAI 证实的估算（包括每天约 100 万美元亏损、峰值基础设施成本约 1500 万美元），这些数字不宜作为确定事实。Google Veo 3.1 确实支持原生同步音频，也提供 4K 输出（部分文档将其描述为生成后升级或特定计费档），但「原生 4K + 原生同步音频 48kHz + 可扩展至 60 秒以上」中，需区分：模型直接生成 4K、生成后升级至 4K、单次生成时长、通过 extension 多次拼接形成更长视频。Google 当前开发者文档甚至建议一般视频生成优先使用 Gemini Omni Flash，把 Veo 3.1 用于场景扩展与末帧控制等特定需求。
  3. 图像生成分场景三强：真实感 / 提示遵循选 FLUX.2 Pro，文字渲染与速度选 Imagen 4，艺术审美 + 原生 2K 选 Midjourney V8.1。没有全能王。
  4. 语音 / 实时翻译：OpenAI GPT-Realtime-Translate（2026-05-07）支持 70+ 输入语言 → 13 输出语言实时同传；识别精度 Gemini 2.5 Pro LibriSpeech WER 2.3% 领先。
  5. 一句话总结：多模态的「读」（图像理解）已经够用且趋于同质化；「造」（视频 / 图像生成）是内容创作赛道的事，对垂直应用的价值取决于具体场景，不能一律说「价值有限」。

维度五：长上下文与知识记忆

最强水平结论

广告窗口和实际可用是两回事：宣传上已到 1M–2M（开源 10M），但真实「多针检索」@1M 仅少数模型领先（约 74%–78%），且一项成绩不能代表长文推理、代码理解、总结与跨文档综合。
  1. 广告口径最大窗口：开源 Llama 4 Scout 标 10M；商用托管中 Gemini 3 Pro 标 2M 最大，Claude 旗舰和 GPT-5.5 标 1M。
  2. 真实长上下文可用性（关键！）：严格多针测试 MRCR v2 8-needle @1M 下，Claude Opus 4.6 约 76–78.3% 领先，GPT-5.5 约 74%；Gemini 3.1 Pro 从短上下文的 85% 崩塌到 1M 的 26%。「可依赖」并无统一定义，74%–78% 通常也不能直接称为可靠；且这仅测多针检索，不代表全部长上下文任务。多数模型可靠上下文约在广告的 50–65%，「中间信息丢失」依然存在。
  3. 单针测试已不能区分能力：needle-in-haystack @1M 主流普遍 >95% 已饱和——厂商宣传「1M 窗口」很大程度是营销口径。
  4. 跨会话知识记忆：官方宣传最强是 OpenAI ChatGPT 的「dreaming」（新记忆系统，2026-06 发布，事实召回 82.8%、偏好遵循 71.3%；OpenAI 官方页面更常用「dreaming」或「新记忆系统」，是否正式称「V3」需证据）。Claude / Gemini 是否具备同等跨会话持久记忆，需分别查阅其截至 8 月 2 日的官方文档，不能仅由 OpenAI 发布 Dreaming 推断竞争对手没有同类能力。
  5. 知识截止：最新模型知识截止 2026-05（Claude Opus 5，2026-07-24 发布）；超过约 500K 上下文后，RAG 检索仍是主流方案。
  6. 一句话总结：长上下文「能塞进去」不等于「能准确找到用起来」——超过 200K 的可靠工作负载，目前公开测试中 Opus 4.6 与 GPT-5.5 在 MRCR v2 上领先，但该结果不能直接推广到所有长上下文任务。

  • 来源 2（窗口口径）[C]：benchlm.ai 上下文对比 | 2026 | 第三方聚合 | 广告 vs 有效窗口

维度六：价格与可及性

最强水平结论

最强模型 API 定价在 $5–10 输入 / $25–50 输出（每百万 token）；价格持续下降但降的主要是次旗舰。中国大陆用户直接使用三家最强官方 API 通常受地区、网络、账号与支付等限制，具体情况随渠道与政策变化。
  1. 最强闭源旗舰 API 定价：Claude Fable 5 = $10/$50（1M 上下文）；Claude Opus 5 = $5/$25；OpenAI GPT-5.6 Sol = $5/$30；Gemini 3 Pro = $2/$12。
  2. 价格在降，但降的是次旗舰：2026-07-30 起 OpenAI 对 GPT-5.6 Luna 降 80%（→$0.20/$1.20）、Terra 降 20%，旗舰 Sol 不降。宏观上 2025 下半年有效 token 均价 -39%，2026 年前 5 个月仅 -6%——经济型模型价格约每 1.1 年减半，旗舰层不跟跌。
