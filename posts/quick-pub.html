最简单的使用方法

  1. 找到 发布博客.cmd。
  2. 把写好的 HTML 文件直接拖到它上面。
  3. 脚本自动完成校验、复制、构建、Git 提交和推送。

也可以双击该文件，然后粘贴 HTML 完整路径。

命令行方式

Set-Location E:\blog
npm run publish -- "C:\文章目录\my-article.html"

支持两个选项

# 只在本地构建，不推送
npm run publish -- "C:\文章目录\my-article.html" --local

# 覆盖同名文章
npm run publish -- "C:\文章目录\my-article.html" --force

安全措施

  • 元数据错误时不会复制文章。
  • 默认拒绝覆盖同名文章。
  • 构建失败会恢复原文章。
  • 暂存区已有内容时停止，避免误提交。
  • posts/ 有其他未发布改动时停止。
  • 推送失败会明确报错，可以处理后重试。
