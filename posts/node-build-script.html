用 Node.js 写一个零依赖构建脚本

2026-07-30 · 技术

有时候你不需要一个框架。你需要的是一个 50 行的脚本，它做三件事：读文件、提取信息、生成页面。没有插件系统，没有主题引擎，没有 node_modules 里那两万个你不知道是什么的东西。

为什么不用现成的？

Hexo、Hugo、Jekyll 都是好东西。但它们解决的问题是"把 Markdown 变成网站"。如果你的文章本身就是完整的 HTML——自带样式、自带排版、自带灵魂——那套一层模板反而是削足适履。

最好的构建工具，是那个你完全看得懂的构建工具。

核心逻辑

整个脚本的核心就是一个正则：

const meta = (html, name) => {
  const m = html.match(
    new RegExp(`<meta\\s+name="${name}"\\s+content="([^"]*)"`)
  );
  return m ? m[1] : '';
};

从每篇文章的 <head> 里提取 title、date、tags。然后排序、生成列表、复制文件。完事了。

幂等性

构建脚本必须是幂等的。跑一次和跑十次，输出应该一模一样。这意味着每次构建前先清空输出目录，而不是"增量更新"。增量更新是 bug 的温床。

这就是全部了。没有 npm install，没有配置文件，没有黑魔法。一个文件，五十行，你随时可以打开它看看它在干什么。
